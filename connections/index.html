ChatGPT auto-submit helper

OPTIONAL LOCAL HELPER · NOT INSTALLED

ChatGPT, with one less click.

The rblvnt browser helper opens a fresh ChatGPT tab and submits the exact question you enter on your start page. It uses your existing ChatGPT login.

Download the Edge / Chrome helper ↓
  1. Extract the downloaded ZIP to a folder.
  2. Open edge://extensions or chrome://extensions.
  3. Turn on Developer mode, choose Load unpacked, and select the extracted folder containing manifest.json.
  4. Reload rblvnt. Look for Auto-submit ready under the ChatGPT box.

This grants the helper access to ChatGPT pages and the listed rblvnt pages. It does not request cookies, history, X, or YouTube access. It sends only after a submission from rblvnt, stops if you interact with the new tab, and never overwrites an existing draft. Prompts travel through temporary extension session storage, not our server. Live submission in your browser is still unverified; changes to ChatGPT may require a helper update. The ZIP includes readable source code.
